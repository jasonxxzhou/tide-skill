## 为什么是"潮汐"

看海的人只看到浪，懂潮汐的人看到月球的引力。

一篇文章、一条视频、一句金句，都只是浪花。**反复出现的口癖、一以贯之的取舍、承认过的失败、没解决过的矛盾——这些才是驱动一个人的引力。**

潮汐蒸馏的不是"他说了什么"（模型早就知道了），而是"**他为什么这样想**"——这部分只存在于具体素材里，是模型永远无法从训练数据中自己获得的东西。

| 会被模型进化吃掉的 ❌ | 潮汐专注于此 ✅ |
|:---:|:---:|
| "独立思考很重要" | "我信独立思考，是因为看了3000个项目后发现最好的想法一开始都被反对" |
| "Step 1: 分析问题类型" | "我遇到创业想法时，本能反应是问它从哪来的——是真实痛点还是编造的" |
| "句式偏好短句" | "我说话直接、用简单词，不确定时说 I suspect" |

生成的每个 Skill 都标注**诚实边界**：基于有限素材、不代表本人立场、哪些是推断——让 AI 知道自己不知道什么。

## 三条蒸馏通道

无论素材是文字还是视频，最终都汇入同一套认知提取流水线：

```
                        ┌─ 路线 A · 人物蒸馏 ──→ 文章/访谈/6路网搜 ──┐
用户输入 ──→ Step 0 分流 ─┼─ 路线 B · 书籍蒸馏 ──→ 整本书分块精读 ────┼──→ 认知提取 → 组装 → 质检 → 交付
                        └─ 路线 C · 视频博主蒸馏 → 抖音爆款视频提取 ──┘
```

| 通道 | 输入 | 产出 |
|------|------|------|
| **人物蒸馏** | 人名 / 文章 / 访谈 / PDF | 思维 Skill |
| **书籍蒸馏** | 整本书（PDF/EPUB/TXT） | 思维 Skill |
| **视频博主蒸馏** ⭐ | 抖音爆款视频链接 / 博主 | 思维 Skill + 文案结构分析 |

### 路线 C · 视频博主蒸馏（核心特色）

**丢进来一个博主的爆款视频链接，得到两样东西：一套他的思维 Skill，一份爆款文案结构拆解。**

```
抖音链接 → 无水印视频下载 → 音频/封面提取 → 语音转写口播稿
        → 口播稿结构拆解（Hook/痛点/价值/CTA）
        → 认知提取（信念/决策/失败/矛盾/思维习惯）
        → [博主名]-perspective/SKILL.md
```

为什么口播稿是金矿：博主对着镜头说话时，**口癖、取舍、叙事套路全部裸露**——比任何二手访谈的蒸馏价值都高。跨视频反复出现的金句才是信念，一次性的只是选题。

支持：
- 单条或批量视频链接（3-10 条爆款为宜）
- 无水印视频 / 封面 / 音频 / 完整口播稿逐字保留
- 爆款文案结构标注（前 3 秒 Hook 类型、痛点-价值-方法-CTA 布局）
- 无转写 API 时可手动补录口播稿，不阻塞蒸馏

## 工作原理

```
Step 0  识别潮路（人物 / 书籍 / 视频博主）
Step 1  素材采集（上传读取 / 6路网搜 / 视频提取）
Step 2  结构化落盘（来源清单 + 提取记录 + 交叉验证）
Step 3  认知提取（三路汇合点）：
        ① 信念及其形成故事（无故事不进入）
        ② 真实决策 + 事后反思
        ③ 本人承认的失败
        ④ 内在矛盾（保留不调和）
        ⑤ 认知边界（具体的"我不懂"）
        ⑥ 思维习惯（第一人称本能反应）
        ⑦ 表达DNA（极简 3+3）
Step 4  摘要确认
Step 5  按 v3 模板组装（第一人称认知上下文，不写推理步骤）
Step 6  质量自检（12 项脚本检查 + 人工清单）
Step 7  交付
```
